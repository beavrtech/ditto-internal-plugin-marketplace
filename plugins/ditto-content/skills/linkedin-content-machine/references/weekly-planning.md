# Planification hebdomadaire

1. Lister les sujets à pousser cette semaine (série vidéo, actus, cas client, lancement, TLA).
2. Pour chaque sujet, choisir les relais selon ce que chacun apporte de crédible. Exemples : Ugo pour l'expertise CDP ; les AEs pour ce que demandent les prospects ; un coach pour l'angle coulisses ; le client pour ses propres mots.
3. Donner à chaque relais un autre angle, un autre chiffre et un autre visuel. Ne jamais coller le même texte à plusieurs comptes.
4. Cadence : la page Ditto poste une fois par jour et jamais le vendredi, sauf les 10 actus RSE ; étaler les posts d'une même personne sur plusieurs jours ; ne pas empiler deux lead magnets sur les mêmes jours ; étaler une même histoire sur plusieurs jours.
5. Prévoir un plan B : un contenu lié à une date externe (par exemple les résultats CDP) est prêt un jour plus tôt.
6. Vérifier dans le calendrier les créneaux vides, les entrées annulées et les posts encore en « Généré par l'IA ».
7. Toujours garder un TLA dans le circuit, pour que les ads ne manquent pas de contenu en fin de semaine.
8. Faire le récapitulatif des visuels et des chiffres déjà utilisés dans la campagne (qui, quand, quel visuel) avant de rédiger.
